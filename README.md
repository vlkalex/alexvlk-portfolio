# alexvlk.com

My personal portfolio site. Built entirely by AI agents following [ai-agent-coding-standards](https://github.com/vlkalex/ai-agent-coding-standards).

**Live:** [alexvlk.com](https://alexvlk.com)

## Why this exists

This isn't just a portfolio. It's a proof of concept for how AI agents can build clean React code when given the right guidelines. Every component was generated by Claude and Codex agents following the same standards I use across my React and React Native projects.

## How it was built

1. Defined the site structure and content through a discovery interview (grill-me skill)
2. AI agents generated the initial site following the component guidelines
3. A second pass refactored everything to match the standards: thin page composers, reusable UI primitives, data separated from components, proper TypeScript types
4. Result: 26 files, no file over 50 lines, clean architecture layers

## Architecture

The project follows the [component guidelines](https://github.com/vlkalex/ai-agent-coding-standards/blob/main/react/component-guidelines.md) strictly:

```
src/
  app/                    # Pages (thin composers only)
    page.tsx              # 18 lines
    sealed-market/page.tsx # 47 lines
    const.ts              # Data separated from UI
  components/
    ui/                   # Reusable primitives (6 components)
    home/                 # Homepage sections (4 components)
    sealed-market/        # Case study sections (6 components)
  types/                  # Shared TypeScript interfaces
```

Key patterns demonstrated:
- **Pages as composers.** Pages import sections and data, nothing else. No logic, no styling decisions.
- **Reusable UI primitives.** TextLink, SectionHeading, StatCard, ScreenshotGrid are used across both pages.
- **Data outside components.** All content lives in `const.ts` files. Components receive data through props.
- **One responsibility per file.** Each component does one thing. Average file length is ~30 lines.
